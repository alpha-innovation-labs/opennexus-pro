Renders the pi TUI message area as one continuous bordered transcript. It re-skins assistant activity (thinking, text, and tool calls), user input, and tool output so a turn reads as a single framed chain rather than a stack of independent blocks. Tron installs its surfaces through pi extension hooks and drives every row through a shared transcript renderer.

## Features
- [[features/assistant-frame/assistant-activity-chain|assistant-activity-chain]]: Joins the thinking, text, and tool calls of one assistant message into one bordered chain with shared walls.
- [[features/assistant-frame/bordered-assistant-text|bordered-assistant-text]]: Renders assistant text inside a border whose corners adapt to the neighbors above and below.
- [[features/assistant-frame/assistant-error-row|assistant-error-row]]: Renders a provider error or abort at the end of the message.
- [[features/assistant-frame/assistant-footer|assistant-footer]]: Renders the duration footer under the content and keeps it and the following prompt one blank line apart.
- [[features/assistant-frame/thinking-tool-bridge|thinking-tool-bridge]]: Computes the shared frame state that lets bridged rows drop their top borders.
- [[features/tool-call/compact-tool-error|compact-tool-error]]: Surfaces a failed tool call as one red error row inside the chain.
- [[features/tool-call/tool-call-interaction|tool-call-interaction]]: Toggles individual tool results by clicking their boxes in the fullscreen transcript.
