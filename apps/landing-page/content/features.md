# Nexus features

- Token-saving defaults keep answers compact and avoid unnecessary context waste.
- The bundled Nexus base system prompt simplifies responses heavily by default.
- Tron compact UI reduces visual overload from thinking, tool calls, and agent activity.
- Tool-call boxes summarize search, read, edit, and validation work without flooding the terminal.
- Answers render as formatted content instead of exposing raw Markdown markers.
- Multi-part human prompts are automatically split into numbered sections.
- Each detected question is summarized into a clear H2-style heading before the answer.
- Nexus keeps track of many asks inside one messy natural-language prompt.
- The custom promptline shows project, branch, context usage, and slashusage details.
- The Nexus startup screen opens with the branded block wordmark.
- The app runs as a terminal-native coding cockpit with a black Nexus visual style.
- Conversation titles update during the session, keeping sessions easier to identify.
- Bundled extensions are available without requiring separate user installation.
- Nexus branding stays consistent across the terminal UX.
- Visual callouts can highlight product value moments such as reduced overload or tracked prompts.
