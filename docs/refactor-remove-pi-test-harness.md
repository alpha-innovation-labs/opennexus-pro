# Refactoring: Remove `pi-test-harness` Integration

## Summary

Remove all code, dependencies, scripts, and references to the `@marcfargas/pi-test-harness` dev-only harness mode from the Nexus codebase.

## Scope

This harness mode is a **development-only smoke test** that:

- Is triggered by the `NEXUS_DEV_TEST_MODE=1` environment variable.
- Loads `@marcfargas/pi-test-harness` at runtime.
- Creates a mock test session with stubbed tools (bash, read, write, edit).
- Executes one scripted turn ("List files in the project") and exits.
- Is invoked via `npm run dev-test`.

It exercises the Pi harness path, **not** the user-facing app. It is not used in production, CI, or any release path.

## Files to Delete

| # | File (relative to repo root) | Purpose |
|---|------------------------------|---------|
| 1 | `apps/tui/src/runtime/harness/isHarnessModeEnabled.ts` | Checks `NEXUS_DEV_TEST_MODE` env var |
| 2 | `apps/tui/src/runtime/harness/runHarnessMode.ts` | Full harness mode runner (mock session, scripted turn, event reporting) |
| 3 | `scripts/wterm/nexus-status-shell.sh` | Shell script that runs `npm run dev-test` (convenience dev script) |

> After deleting files 1 and 2, the `apps/tui/src/runtime/harness/` directory will be empty. **Delete the empty directory.**

## Files to Edit

### 1. `apps/tui/src/runtime/runAppWithExtensionFactories.ts`

**Remove the following lines:**

- Line 32: `import { isHarnessModeEnabled } from "./harness/isHarnessModeEnabled.js";`
- Line 33: `import { runHarnessMode } from "./harness/runHarnessMode.js";`
- Lines 127–131 (the entire harness-mode guard block):
  ```ts
  if (isHarnessModeEnabled()) {
    await runHarnessMode({ argv: args, extensionFactories });
    printExitMessage();
    return;
  }
  ```

**After removal**, the code flow proceeds directly from `resolveBundledExtensionFactories` to the real `main()` import:

```ts
  phaseStartedAt = performance.now();
  const { main } = await import("@earendil-works/pi-coding-agent");
```

This is the correct and only remaining path.

### 2. `package.json` (root, monorepo root)

**Remove from `devDependencies`:**

- Line 58: `"@marcfargas/pi-test-harness": "^0.6.1",`

**Remove the script:**

- Line 17: `"dev-test": "npm run generate:package-info && NEXUS_DEV_TEST_MODE=1 tsx -- apps/tui/src/index.ts",`

### 3. `scripts/release/binary/getExternalReleasePackages.mjs`

**Remove from `BASE_EXTERNAL_RELEASE_PACKAGES` array:**

- Line 10: `"@marcfargas/pi-test-harness",`

This package should no longer be listed as an external release dependency since nothing in the release build references it.

### 4. `pnpm-lock.yaml`

**Run `pnpm install` after editing `package.json`** to regenerate the lock file. The `@marcfargas/pi-test-harness` entries (lines ~117, ~1016, ~4159) will be removed automatically.
