## Pattern summary

1. **Filtered scope:** This list now keeps only coding harnesses: tools that can generate, edit, run, or orchestrate code through an IDE, CLI, terminal, web workspace, or autonomous agent.
2. **Removed categories:** Pure PR review, static analysis, security scanning, memory/context-only, and code-quality dashboards were removed even when they use AI.
3. **Monetization pattern:** Usage credits, model access, requests, or token bundles remain the most common individual monetization path among coding harnesses.
4. **Non-token monetization that remains:** The strongest non-team alternatives are hosted/cloud agents, premium IDE/editor capability, app deployment/hosting, private context/indexing, and support.
